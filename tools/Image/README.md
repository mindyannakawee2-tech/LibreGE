# LibreGE Image Tool

Command-line image asset utility for LibreGE.

## Commands

libre-image info <file>

libre-image validate <file>

libre-image convert <input> <output.png>

## Supported input

PNG
JPEG
BMP
TGA
GIF
PSD
HDR
PIC
PNM

## Output

PNG
