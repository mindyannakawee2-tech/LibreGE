# LibreGE
LibreGE is an continuation of NijeEngine, cuz I deleted Windows

**NOTE** : **LibreGE is _EXPERIMENTAL_ and only supports Linux for now**

# Use LibreGE
```
git clone --recurse-submodules https://github.com/mindyannakawee2-tech/LibreGE.git PROJECT_NAME
cd PROJECT_NAME

./install-lbbe.sh

lbbe setup
lbbe build
lbbe run
```
