# OpenSrcGE

OpenSrcGE is an open-source game engine project.

## Status

Early development.

## Project Structure

- `src/` — engine source code
- `assets/` — engine/demo assets
- `docs/` — documentation
- `examples/` — example projects
- `tests/` — tests

## Goals

- Lightweight
- Open source
- Easy to modify
- Cross-platform
- Friendly for indie game development
