# LibreGE
LibreGE is an continuation of NijeEngine, cuz I deleted Windows

**NOTE** : **LibreGE is _EXPERIMENTAL_ and only supports Linux for now**

# Use LibreGE
```
git clone https://github.com/mindyannakawee2-tech/LibreGE.git YOURGAMENAME
cd YOURGAMENAME
./install-lbbe.sh
lbbe build
lbbe run
```
